# Privacy / Terms / Support の変更案（未公開）

現行公開ページは変更していない。以下は安全性コードの公開前に社長/CTOが確認する草案。

## Privacy案
削除完了後も、遅延アップロードの清掃に必要なオブジェクト位置の最小記録を24時間保持し、再取得を禁止します。この記録は匿名ではありません。アップロード処理は10分で打ち切る設計です。
登録データ削除を受け付けると、新しい素材送信を停止し、通常素材・下書き・接続情報等の消去を進めます。未確定送信がある場合、削除後の重複送信防止のため、用途を分離したHMAC識別子、承認消費・試行状態、素材照合情報等の必要最小限の記録を期限付きで保持します。仮名記録は匿名情報ではありません。記録を消去しても送信承認を再発行しません。
隔離実装の暫定値は30日レビュー、最大90日仮名記録の消去候補、通常素材等の消去完了目標24時間です。法令で決まった期限ではなく、公開前に適用範囲、例外、削除請求、ホスティングログ/バックアップと定期処理の運用を確定します。TikTokへ既に到達し得る内容の削除はTikTok側で管理します。

## Terms案
素材準備とTikTokへの引き継ぎは別です。Sandboxの送信承認は対象アカウント・素材・回数・期限を限定し、利用登録や素材使用同意だけで発行されません。結果不明・DB障害・削除要求中は送信を停止します。承認の失効、登録削除や再登録によって回数は補充されません。一般公開Productionの提供条件は別途審査・検証完了後に告知します。

## Support案
メディアURLの全体取得/SHA照合は確認済みですが、Sandboxの過去2試行はUNKNOWNで、TikTok Inbox受信成功は確認できていません。再送や状態確認を勝手に実行せずサポートへ相談してください。台帳の内部ID・HMAC・Secret・トークン・署名付きURLを送らないでください。
削除処理中にエラーが出た場合は、送信を停止したまま削除処理を再開できます。削除の目標期限を過ぎた場合のサポート対応、定期処理、保持例外は公開前に確定します。
