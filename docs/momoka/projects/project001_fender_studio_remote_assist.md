# Project-001｜Fender Studio 遠隔デスクトップ補助方式

**目的:** Fender Studioを実行する社長のWindows／Mac環境に対して、必要な場合だけ遠隔補助を行う。ローカル制作・ファイル連携を標準経路とし、本方式は画面を見ながらの作業補助が必要な場合に限定する。

## 1. 現時点の位置付け

Fender Studioはネイティブアプリとして動くため、通常のWeb操作連携だけで直接操作できるとは限らない。ローカル端末連携は設定されておらず、遠隔GUI操作の可否は接続方式と端末OSに依存する。したがって、本方式は**接続テストを通過するまで実験的運用**とする。

> **標準方針:** 直接操作の可否にかかわらず、音源書き出しとmanifestを用いるローカル制作・ファイル連携方式を必ず併設する。遠隔接続が途切れても、制作・分析サイクルは停止しない。

## 2. 接続前の安全条件

| 項目 | 必須条件 | 理由 |
|---|---|---|
| 端末アカウント | 音楽制作専用の標準ユーザー。管理者権限は不要。 | 不要なシステム変更を防ぐ。 |
| 作業フォルダ | `FieldRise_MusicAI/Project001_FenderStudio/`のみ。 | 関係のない個人・会社データを隔離する。 |
| 認証情報 | パスワード、二段階認証コード、決済情報を共有しない。 | 認証・金銭情報を保護する。 |
| 接続時間 | 社長が立ち会う必要がある編集セッションだけ有効化する。 | 常時・無人接続を避ける。 |
| 送信・公開 | 書き出し、共有、公開、削除などの外部影響操作は社長の明示承認後に実行する。 | 誤操作と無断公開を防ぐ。 |
| 音源権利 | 作業対象は自社保有または利用許諾を確認した素材に限る。 | 著作権・利用規約リスクを防ぐ。 |

## 3. 準備手順

1. 社長のPCにFender Studioを通常どおりインストールし、社長本人がログインする。
2. `Project001_FenderStudio`専用フォルダを作成し、001・002の正本、候補音源、書き出し先を分離する。
3. 端末とブラウザ上の遠隔画面を結べる方式を、社長が選択して用意する。接続コード、認証情報、決済情報はチャットへ送らない。
4. 共有前に、無機密のテストWAVをFender Studioへ読み込み、トラック移動、再生、停止、WAV書き出しまでを社長立会いで確認する。
5. テストに成功した場合だけ、001または002のコピーを使用して編集する。正本ファイルは読み取り専用で保管する。

## 4. 接続テストの合格基準

| テスト | 合格条件 | 不合格時の扱い |
|---|---|---|
| 画面表示 | Fender Studioの波形とトランスポートが安定して見える。 | ローカル制作・ファイル連携へ戻す。 |
| 操作反応 | 再生、停止、トラック選択、フェーダーの小変更が遅延なく確認できる。 | 直接編集を行わない。 |
| 音声確認 | 社長が端末側でノイズ・同期ずれを確認できる。 | 書き出し後の検証だけに限定する。 |
| 書き出し | テストWAVを所定フォルダへ出力できる。 | ファイル共有経路を見直す。 |
| 権限境界 | 専用フォルダ以外にアクセスしない。 | 接続設定を見直す。 |

## 5. 遠隔補助時の操作範囲

遠隔補助では、001・002再現に直接関係する操作だけを対象とする。対象は、トラック読み込み、トリミング、フェード、音量、パン、最小限のEQ・空間処理、書き出し設定、プロジェクト保存である。新規アカウント作成、購入、プラグイン追加、他サービスへの公開、ライブラリやOS設定の変更は対象外とする。

| 作業 | 実行可否 | 承認条件 |
|---|---|---|
| 001／002のコピー編集 | 可 | 編集変数を事前に一つへ固定する。 |
| フェード、音量、パン、EQ調整 | 可 | 指定された検証変数の範囲に限定する。 |
| WAV書き出し | 可 | ファイル名・保存先を社長が確認する。 |
| プロジェクト上書き保存 | 条件付き | 原本でなく版番号付きコピーのみ。 |
| 外部公開・アップロード | 不可 | 社長の明示承認後に別手順で行う。 |
| 購入・課金・アカウント変更 | 不可 | 遠隔補助の対象外。 |

## 6. 001・002の遠隔編集手順

### 001

1. 001参照音源と候補音源を読み込む。参照音源はロック・ミュートする。
2. 0:00〜2.00秒を確認し、今回の一変数だけを反映する。現段階ではStereo幅のdual-mono化を優先する。
3. 2.00秒のPiano導入、後段のDrums、全体の音量は固定する。
4. `001_mix_vNN.wav`を48 kHz／24-bit／Stereoで書き出し、manifestを更新する。
5. 社長がクリック音・金属音・Bass以外の混入・Loopを聴取する。

### 002

1. 002の参照音源と候補音源を読み込み、拍感と採用テンポを確認する。
2. 最初は0〜8秒のBass／伴奏の密度遷移だけを調整する。
3. Piano導入、Drums、空間は一つずつ後段で扱う。
4. `002_mix_vNN.wav`とmanifestを出力する。
5. 社長が遷移、過密化、Loop、BGMとしての聞きやすさを確認する。

## 7. 停止条件と復旧

接続遅延、誤クリックの恐れ、意図しない保存先、専用フォルダ外へのアクセス、認証画面、購入・公開画面が出た場合は、直ちに操作を止める。プロジェクトは版番号付きコピーへ保存し、最後に確認済みWAVとmanifestをローカル制作・ファイル連携方式に戻してから再開する。
