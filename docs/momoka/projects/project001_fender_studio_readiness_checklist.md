# Project-001｜Fender Studio 実行前チェックリスト・引き渡し票

**対象:** Cafe 001・002再現検証
**利用目的:** ローカル制作・ファイル連携方式と遠隔デスクトップ補助方式の、共通の開始条件と品質確認を統一する。

## A. 方式の選択

| 確認項目 | ローカル制作・ファイル連携 | 遠隔デスクトップ補助 |
|---|---|---|
| 標準利用 | 常に利用可能な基本方式 | 接続テスト合格時のみの補助方式 |
| 社長の作業 | Fender Studioで編集・書き出し | 立会いのもとで編集を確認・承認 |
| COOの作業 | 測定、編集値設計、再分析、GitHub記録 | 上記に加え、許可された画面内作業の補助 |
| 不可の操作 | 認証情報・決済情報・公開操作の共有 | 認証・購入・公開・専用フォルダ外の操作 |

> **開始判定:** 遠隔方式の接続テストに不合格または不安がある場合は、直ちにローカル制作・ファイル連携方式のみで進める。制作・分析は止めない。

## B. 編集開始前チェック

- [ ] 対象は001または002のどちらか一曲に固定した。
- [ ] 参照音源の正本は読み取り専用の`00_reference/`にある。
- [ ] 編集対象は版番号付きコピーであり、正本ではない。
- [ ] 今回変える項目を一文で決めた。
- [ ] 変更しない項目をmanifestに記載した。
- [ ] 001では0〜2秒、002では0〜8秒の確認区間を先に決めた。
- [ ] 公開・アップロード・購入・アカウント変更は今回の作業範囲に含まれない。

## C. 001の完成前チェック

| 確認領域 | 合格条件 | 社長の確認 | COOの測定 |
|---|---|---|---|
| Bass開始 | 0:00からBassが存在し、無音でない。 | [ ] | 信号開始時刻 |
| 楽器構成 | 0〜2秒にPiano、Drums、Melody、効果音が知覚されない。 | [ ] | ステムまたは全体ミックスの補助指標 |
| 帯域 | Low比率を高め、Low-midを抑える。 | [ ] | Low／Low-mid比率、スペクトル重心 |
| 空間 | 左右差が小さく、中央に安定する。 | [ ] | Side/Mid比、左右相関 |
| ノイズ | クリック、金属音、クラッチ音、機械音がない。 | [ ] | 聴取記録を優先 |
| Loop | 終端8秒→冒頭8秒で不自然な切れ目がない。 | [ ] | 聴取記録を優先 |

## D. 002の完成前チェック

| 確認領域 | 合格条件 | 社長の確認 | COOの測定 |
|---|---|---|---|
| テンポ | Fender Studioのグリッドと拍感の採用値をmanifestに記録した。 | [ ] | 必要時に再推定 |
| 導入遷移 | 0〜8秒でBassから伴奏へ自然に進む。 | [ ] | RMS・帯域推移 |
| Piano | 導入時刻と密度が過密でない。 | [ ] | 遷移時刻プロキシ |
| Drums | 最小限で、展開を急がせない。 | [ ] | 聴取記録を優先 |
| 空間・音量 | 声の上に載せても邪魔にならない。 | [ ] | 全体RMS・Stereo補助指標 |
| Loop | 終端から冒頭へ自然に循環する。 | [ ] | 聴取記録を優先 |

## E. 版管理・引き渡し票

提出時は、次の内容をコピーして`05_notes/`のmanifestまたはGitHub Issue／報告に記載する。

```text
対象: 001 / 002
版番号: vNNN
方式: local-file / remote-assist
今回の一変数: 例）0〜2秒のStereo幅をdual-monoにする
固定条件: 例）Bass開始0:00、無音なし、Piano導入2秒、後続Drums
Fender Studioプロジェクト名:
書き出しファイル:
音声仕様: 例）WAV / 48 kHz / 24-bit / Stereo
主観チェック: Bass以外の混入 [なし/あり]、クリック [なし/あり]、Loop [合格/要修正]
未確定事項:
```

## F. COOへの測定依頼

提出されたWAVと引き渡し票を受けたら、COOは以下を返す。

| 出力 | 内容 |
|---|---|
| 測定結果 | 時間、RMS、Low／Low-mid比率、スペクトル重心、Side/Mid比、ダイナミクス。 |
| 判定 | Fact／Hypothesis／Evidence／Resultを分離する。 |
| 次の修正 | 最も影響の大きい一変数だけを指定する。 |
| GitHub記録 | 分析データ、詳細報告、`latest_report.md`を更新する。 |
