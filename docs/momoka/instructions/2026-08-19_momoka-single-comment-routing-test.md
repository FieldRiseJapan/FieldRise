# 桃花向け｜単独コメント通信ルール確定・実動テスト指示

**対象：桃花**  
**目的：桃花から彩花への単独コメント通信経路を正式確定し、実動確認する**

## 1. 正式通信ルール

### ① 単独コメント
通常の進捗報告・正式報告に該当しない、桃花から彩花への短いコメント・確認・連絡は、

`cto/inbox/momoka-comments.md`

へ記録してください。

### ② 正式報告
受領・進捗・完了・停止・ブロッカー等の正式報告は、

`docs/momoka/reports/latest_report.md`

を正式な報告先としてください。

### ③ 彩花 → 桃花の正式指示
桃花向けの新規正式指示は、

`docs/momoka/instructions/`

を唯一の正本としてください。

`cto/outbox/` や旧来の指示ファイルを、新規正式指示の正本として扱わないでください。

## 2. 実動テスト

通信経路が実際に機能することを確認するため、テスト用の単独コメントを1件、

`cto/inbox/momoka-comments.md`

へ実際に書き込んでください。

コメントには、以下を含めてください。

- テストであること
- 桃花から彩花への単独コメントであること
- 書き込み日時
- テスト完了の旨

## 3. 書き込み後の確認

以下を確認してください。

1. `cto/inbox/momoka-comments.md` が存在すること
2. 今回のテストコメントが実際に保存されていること
3. GitHubへPushされていること
4. Commit SHAを記録すること
5. 彩花側から確認可能であること

## 4. 完了報告

テスト完了後、正式報告先である

`docs/momoka/reports/latest_report.md`

へ結果を反映してください。

報告には必ず以下を記載してください。

- 完了状況
- テストコメントの保存先
- Commit SHA
- Push先
- 未完了・ブロッカー
- 次に確認するファイル

## 5. 運用ルール

今後、桃花から彩花への「ちょっとしたコメント」は `cto/inbox/momoka-comments.md` を確認すればよい状態に統一してください。

正式報告は `docs/momoka/reports/latest_report.md`、正式指示は `docs/momoka/instructions/` とし、3系統を混同しないでください。

今回のテストでは、実際にファイルを書き込み、Pushまで行って通信経路を検証してください。
