# 桃花への正式指示書｜Gmail重要イベント補助通知

## 社長決定

桃花から社長への重要イベント通知について、既存Gmailを補助通知経路として使用する。正式報告の正本は従来どおり `docs/momoka/reports/latest_report.md` とし、Gmailはこれを置き換えない。

## 固定条件

| 項目 | 決定内容 |
|---|---|
| 受信先 | `hoshininegaiwo.ppp@gmail.com` |
| 送信頻度 | 重要イベント時のみ |
| 初回確認 | テストメールを1通だけ送信する |
| 正式報告書 | `docs/momoka/reports/latest_report.md` |
| GitHub Issue | 正式なタスク単位および受領・Claim確認の経路として維持する |

## 送信対象

重要イベントとは、作業のブロック、秘密情報を含まない重要な設定確認、社長の判断が必要な事象、または社長が明示して送信を求めた完了・到達確認を指す。日常的な進捗や同一状態の重複報告は送信しない。

## 情報保護

メール本文、件名、添付ファイルには、`LINE_TARGET_ID`、Channel Access Token、Channel secret、GitHub Actions Secretの値、または同等の秘密情報を記載してはいけない。

## 送信統制

初回テストメールおよび以後の重要イベント通知は、送信前に宛先・件名・本文を社長へ確認し、明示承認を得てから送信する。送信後の到達確認は、社長の確認をもって完了とする。

**社長決定：本指示書をGmail重要イベント補助通知の正式運用として扱う。**
