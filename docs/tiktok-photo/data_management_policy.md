# Creator Studio 投稿データ管理・公式音源確認方針

2026-10-10 社長決定。Production反映・実投稿は別途承認まで禁止。

## 保持とバックアップ

| 状態 | 方針 |
|---|---|
| 投稿準備中 | 作業データを保持 |
| TikTok下書き保存済み | 公開投稿完了ではない。保持 |
| 投稿予定・予約中 | 公開投稿完了ではない。保持。本ツールは予約実行しない |
| 投稿完了・社長確認済み | JSONバックアップは必須ではない |
| 投稿失敗・状態不明 | 保持 |
| 音源照合未完了 | 確認記録を保持 |

JSON出力は任意の手動操作。投稿後の自動JSON出力、投稿済みを理由とした自動削除、一括整理、localStorage初期化は行わない。バックアップ不要は削除許可ではない。保存期間・投稿完了後の削除方式は未決定。既存の明示確認付き手動削除は変更せず、新しい自動整理機能は作らない。

localStorageは同じOrigin・Chromeプロファイルの端末保存、JSONは任意の持ち運び用バックアップ。写真本体はどちらにも永続保存しない。元画像は社長が保持し、セット再編集時に再選択する。

## 投稿完了

TikTok下書きとCreator Studioセットは別管理。URL・日時を入力し、社長が公開投稿完了を明示確認した場合のみ本人申告の投稿済み記録へ変更する。TikTok APIでの自動取得・成功保証ではない。失敗・不明・下書き・予定を投稿済みへ変更しない。

投稿記録のURLから投稿先を確認し、正式アカウントRuna-Girl8215の投稿であることを社長が確認する。音源照合結果は投稿済み状態と独立。完了確認を行ってもISRC・ID・利用条件・収益を確認済みにしない。

## 音源の別管理

既存設計の楽曲名・アーティスト・SoundOn配信情報、取得済みISRC／SoundOn ID／TikTok ID／公式URL、Studioで観察した情報、照合根拠・日時・下書き再編集保持を保持する。未知の識別子は空欄／未確認。5状態を維持し、複製は本人照合・下書き確認をリセット。

照合順：Runa-Girl8215で検索→タイトル・アーティスト・時間・ジャケット・SoundOnリリース・識別子・公式音源URLを比較。分割曲はタイトルだけで同一と扱わない。TikTok側の抜粋時間とSoundOnのフル音源時間を混同せず、対応根拠を確認する。

検索表示、編集で選択、当該用途の利用許可、配信識別一致、収益対象は独立項目。選択・下書き保持だけで他をPASSにしない。利用条件・識別対応が不明なら未確認を維持。

## 標準工程

社長の画像→Creator Studioで比率・順序・切抜→英語投稿文→画像ZIP→TikTok Studioで写真読込→アーティスト検索→本人が音源照合・選択→下書き再編集で内容と音源確認→公開は社長の別途判断。

ZIPは画像書出しで、音源未確認でも利用可。準備完了は配信識別・音源一致・ビジネス利用・投稿内容・本人最終確認・下書き保持を確認して判定。画像から動画への強制変換、元音声埋込による公式音源認定、印税計算・保証はしない。
