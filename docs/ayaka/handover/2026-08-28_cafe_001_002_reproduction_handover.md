# 彩花CTO向け｜Cafe 001・002 再現候補の設計・一変数実験 引き継ぎ

**作成日:** 2026-08-28（GMT+9）
**作成者:** 桃花COO
**対象:** Cafe 001・002の次回Suno候補およびFender Studio書き出し
**依頼事項:** 下記の別プロファイルと実験順に基づき、最初の候補設計を作成する。

## 引き継ぎ結論

解析システムは、001・002の正本自己比較でスコア100.00、時間軸再現度`trajectory_distance` 0.0000を確認し、GitHub Actionsのクリーン環境でも回帰に成功した。[1] これにより、候補を受領し次第、同一条件での比較・順位付け・次の一変数提案ができる状態である。

> **001と002を同じ音作りのKPIに統一しない。** 001は導入0〜2秒の低域集中と中央定位、002は導入0〜8秒の密度遷移を別々に設計・評価する。

本資料は、公開済み音源のメロディ、歌詞、固有の演奏表現または録音そのものを複製する指示ではない。候補は常に**独自の曲素材・独自の旋律**として制作し、比較対象は構成、密度、帯域、空間、立ち上がりという抽象的な音響特性に限定する。

## 正本保護と候補提出条件

001／002の正本FLACは読み取り専用の比較対象であり、編集・上書き・削除をしない。候補は原則Gitへ保存せず、音源ハッシュ、ファイル形式、共有URL、書き出し仕様、実験条件をmanifestで追跡する。[2]

| 項目 | 必須条件 |
|---|---|
| 候補の書き出し | 優先: Stereo WAV、48 kHz、24-bit。MP3はスクリーニング用。 |
| 実験記録 | Prompt全文、Negative指定、Weirdness、Safe Zone、Style Influence、Strong、Duration、変更変数、固定条件。 |
| 変更原則 | 1候補群で変える設計変数は1つだけ。他の条件は固定する。 |
| 受領後の流れ | manifest登録 → 001/002別プロファイル解析 → 必要時の補助的stem確認 → 聴取確認 → 次の一変数提案。 |
| 判定上の制約 | 全体ミックス測定だけで、特定楽器・クリックノイズ・Loopの不存在を断定しない。 |

## 001｜導入0〜2秒を先に設計する

001は、最初の2秒における**低域集中、少ないLow-mid、強い中央定位**を最優先とする。Piano、Drums、空間、Loopはこの導入が確認できた後に段階的に扱う。

| 001正本プロファイル（0〜2秒） | 基準値 | 設計上の解釈 |
|---|---:|---|
| RMS | -22.64 dBFS | 過度に押し出さず、低域の土台として安定させる。 |
| Low（20〜180 Hz） | 96.68% | 低域を主成分にする。低域素材を重ねすぎない。 |
| Low-mid（180〜2,000 Hz） | 3.04% | 中域の伴奏・明瞭な倍音・早いPiano導入を抑える。 |
| スペクトル重心 | 113.7 Hz | 重心を低く保つ。 |
| Side/Mid | -32.40 dB | 導入の低域を中央に置き、広げすぎない。 |
| 持続信号開始 | 0.40秒 | 冒頭から音を詰め込まず、立ち上がりを比較する。 |

### 001の実験順

| 実験ID | 一変数 | 固定するもの | 合格確認の主眼 | 次へ進む条件 |
|---|---|---|---|---|
| `001-E01` | 0〜2秒をBass主体の導入にするか | BPM、曲尺、Piano/Drumsの開始時刻、空間系、他の生成設定 | 導入の低域集中と持続開始 | Low／Low-mid比、RMS、聴取でBass土台が成立。 |
| `001-E02` | Bassの倍音・Low-mid量 | `001-E01`で成立した導入構成 | Low-mid過多の抑制 | 低域が濁らず、重心・帯域比が近づく。 |
| `001-E03` | Bass導入のStereo幅 | 音色、BPM、導入構成 | 中央定位の維持 | Side/Midが広がりすぎず、モノラルでも安定。 |
| `001-E04` | Pianoの導入時刻のみ | Bass音色・幅、Drums、曲尺、生成設定 | Bass導入を壊さない後続のPiano | 0〜2秒KPIを崩さず、聴取で自然。 |
| `001-E05` | Drums／空間の導入時刻または強さのみ | 前段の合格条件 | 導入の明瞭さと後続の推進力 | クリック感・濁り・急な広がりがない。 |

**彩花への最初の設計依頼:** まず`001-E01`のために、0〜2秒を「中央に置いた穏やかな低域の土台」とする**独自インストゥルメンタル**の候補設計を1本作る。PianoとDrumsの有無・開始時刻、BPM、曲尺、生成設定はmanifestに固定し、次候補ではBass導入の有無だけを変える。

## 002｜導入0〜8秒の密度遷移を設計する

002は、Bassだけの瞬間値に寄せるのではなく、最初の8秒での**持続信号、Low／Low-mid配分、RMS、Onset、層の増え方**を時間軸で管理する。PianoとDrumsを同時に変更しない。

| 002正本プロファイル（0〜8秒） | 基準値 | 設計上の解釈 |
|---|---:|---|
| RMS | -20.31 dBFS | 8秒の中で密度を保ちつつ、急激に飽和させない。 |
| Low（20〜180 Hz） | 18.98% | 低域のみを主役に固定しない。 |
| Low-mid（180〜2,000 Hz） | 80.97% | 中低域の伴奏的な質量を主成分にする。 |
| スペクトル重心 | 477.9 Hz | 001より明るく、しかし高域に寄せすぎない。 |
| Side/Mid | -7.19 dB | 001より空間的だが、過度な拡散は避ける。 |
| 持続信号開始 | 0.20秒 | 早めに音の土台を確立する。 |
| Low優勢窓割合 | 4.37% | 低域だけの状態を長く続けない。 |

### 002の実験順

| 実験ID | 一変数 | 固定するもの | 合格確認の主眼 | 次へ進む条件 |
|---|---|---|---|---|
| `002-E01` | 0〜8秒における基礎レイヤーの開始時刻 | BPM、音色群、曲尺、空間系、他の生成設定 | 0.20秒前後の持続信号開始 | 冒頭が空白にならず、急な密度跳躍もない。 |
| `002-E02` | 第2レイヤーの導入時刻のみ | `002-E01`の基礎レイヤー、BPM、音色群 | 8秒までの密度遷移 | RMS／Onset軌跡とLow-mid主体が近づく。 |
| `002-E03` | Pianoの音色または開始時刻の片方のみ | 基礎・第2レイヤー、Drums、空間系 | 中低域の質量とPianoの自然な接続 | 001型の低域偏重にならず、音が詰まらない。 |
| `002-E04` | Drumsの導入時刻または強さのみ | それまでのレイヤー、Piano、空間系 | 密度の推進とOnset | 大きな突発Onset・クリック感がない。 |
| `002-E05` | Stereo幅のみ | 楽器配置、導入時刻、BPM、音色 | Side/Midの適正化 | 空間の存在感と中央の安定が両立する。 |

**彩花への最初の設計依頼:** まず`002-E01`のために、0〜8秒で中低域の伴奏的な質量を徐々に形成する**独自インストゥルメンタル**の候補設計を1本作る。次候補では、それ以外を固定して第2レイヤーの導入時刻だけを変更する。

## 提出する設計パッケージ

彩花は候補を生成またはDAWで準備する前に、001用・002用それぞれ1枚の実験manifestを作成する。実験manifestの標準書式はリポジトリ内の[Suno一変数実験テンプレート][3]を使う。

| 提出物 | 001 | 002 |
|---|---|---|
| 最初の実験ID | `001-E01` | `002-E01` |
| 設計の焦点 | 0〜2秒のBass主体・中央定位 | 0〜8秒の基礎レイヤー開始・密度遷移 |
| 固定項目 | Promptの共通部分、Negative、Weirdness、Safe Zone、Style Influence、Strong、Duration、BPM、曲尺 | 同左 |
| 次候補で変える唯一の項目 | Bass導入の有無 | 第2レイヤーの導入時刻 |
| 桃花への返却物 | 音源共有URLまたはWAV、manifest、書き出し仕様 | 音源共有URLまたはWAV、manifest、書き出し仕様 |
