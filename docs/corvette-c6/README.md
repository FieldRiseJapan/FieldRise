### 2026-11-22｜左前タイヤ・空気圧監視（TPMS）警告
- **部位:** 左前タイヤ／TPMS（ユーザー申告）
- **症状:** タイヤ空気圧関連の警告・エラー表示が発生。保険用GPS機器を取り外した後も警告が継続。
- **点検場所:** 友人のところ（詳細は非記録）
- **点検:** 車両に診断コンピュータを接続したが、異常を特定できなかった。使用機器、読取対象モジュール、故障コードの有無は未確認。
- **実施作業:** バッテリーのマイナス端子を一度取り外し、約10分間放置後、再接続。
- **結果:** エラー表示が消え、表示上は正常状態に復帰（2026-11-22時点）。
- **原因判定:** 未特定。バッテリー再接続による表示・制御状態のリセットで解消した可能性はあるが、TPMSセンサーや受信系の故障が直ったことを示すものではない。
- **未確認事項:** 左前タイヤの実測空気圧、センサーID/電池状態、TPMS対応診断機での通信・故障コード、再発の有無。
- **再発時:** 冷間時の4輪空気圧を指定値と照合し、TPMS対応診断機で左前センサーの受信状況と故障コードを確認する。警告が消えていても空気圧そのものは点検する。
- **記録元:** 2026-11-22のオーナー本人報告。
