## 3. 灯火類・LED化調査
- 重点: ルームミラー下の左右読書灯を白色LEDに変更したい
- 要確認: 純正電球の口金、形状、実測寸法、個数、極性、取り外し手順、車両側制御との相性
- 既存の外部情報に「194/T10」と「212-2」の相反する記載あり。現車確認または純正部品番号の照合まで**未確定**
- 足元ライト: 青色LED化を検討中。既存球の写真あり。交換部品の確定には現車ソケット適合を確認する
- その他: グローブボックス、ラゲッジ、バニティ、ヘッドライト、ウインカー、テール、ナンバー灯を順次調査
- 日本の保安基準・車検適合性も用途別に確認する

## 4. 電装・診断に関する既知情報
- TPMS警告が発生。外付け保険用GPS機器を外した後も警告が継続したため、干渉原因と断定しない
- Android対応の日本語OBD診断アプリ・機器を検討中。エンジン/AT/ABS/TPMSの対応可否は製品別に検証
- エンジン停止後のアクセサリー通電はドア開放で終了する挙動を確認
- ドライブレコーダーZDR-015の表示日時が初期値だったため再設定が必要

## 5. 今後の調査範囲
ライト・室内電装、警告表示、TPMS、エンジン、AT、ABS、故障診断、消耗品、メンテナンス、純正操作方法。
