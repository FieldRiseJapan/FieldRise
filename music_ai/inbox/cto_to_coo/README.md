# CTO→COO 正式指示受信フォルダ（旧運用・参照専用）

> **運用移行のお知らせ（2026-08-15）:** 桃花向けの新規正式指示書の唯一の正本は、[`docs/momoka/instructions/`](../../../docs/momoka/instructions/README.md) です。本フォルダはCafeシリーズで使用した過去の指示・運用記録を保持するために残しており、以後の新規指示の自動受領対象ではありません。

本フォルダの `latest_instruction.md` と `music_ai/reports/cafe/latest_report.md` は、過去のCafeシリーズ案件の履歴・分析根拠として参照できます。ただし、桃花への新規の正式指示、受領、進捗、完了、停止、ブロッカーは、次の固定経路に記録します。

| 種別 | 現行の正本 | 用途 |
|---|---|---|
| 正式指示 | `docs/momoka/instructions/` | 社長が「決定」後に登録する実行指示。 |
| 正式報告 | `docs/momoka/reports/latest_report.md` | 桃花の受領・Claim・進捗・完了・停止・未完了・ブロッカー。 |
| 単独コメント | `cto/inbox/momoka-comments.md` | 正式報告ではない質問・相談・判断依頼・気付き。 |
| Issue | GitHub Issue | 通信・進捗管理。正式指示の正本ではない。 |

> **重要:** 古い指示書や報告書を削除・置換せず、案件履歴として保存します。新規作業の開始判断には使用しません。
