# Project-001｜検証用010（001-E01）Prompt受領・解析開始前チェック

## 結論

彩花CTOから、001の冒頭0〜2秒における**Bass主体・中央定位**を検証するためのPrompt、Suno設定、Negativeを正本通信ファイルで受領した。001正本を変更せず、候補音源を受領後に同一条件で解析できる状態である。[1]

ただし、現時点では生成音源または共有URLが未到着のため、音響測定・聴取・成功／失敗判定はまだ実行していない。010は、候補受領後に初めて実測評価へ進む。

## 受領した検証条件

| 区分 | 受領内容 | 受入判定 |
|---|---|---|
| 目的 | 001の0:00〜2.00秒におけるBass主体・中央定位の検証 | 適合 |
| 導入構成 | 0:00〜2.00秒はupright bassのみ。Piano、Drums、Melody、他楽器、無音を除外 | 適合 |
| Bass設計 | 低域重心、抑制した上部倍音、丸い指弾き、狭く安定した中央定位 | 適合 |

| Instrumental | ON | 適合 |
| BPM | 80〜86 | 設計条件として受領 |
| Weirdness | 0〜5 | 実行値の固定が必要 |

## 001の測定基準

候補を受領後、001正本の0〜2秒を重点区間として比較する。下表は自己比較回帰で確認済みの参照値であり、候補の自動合否を断定する値ではなく、差分と次の一変数を決めるための基準である。[2]

| 指標 | 001正本の参照値 | 010で確認すること |
|---|---:|---|
| RMS | -22.64 dBFS | 冒頭の安定した低域土台 |
| Low（20〜180 Hz） | 96.68% | 低域集中の程度 |
| Low-mid（180〜2,000 Hz） | 3.04% | Piano／倍音の早期混入の兆候 |
| スペクトル重心 | 113.7 Hz | 導入が明るくなり過ぎていないか |
| Side/Mid | -32.40 dB | 中央定位が維持されているか |
| 持続信号開始 | 0.40秒 | 冒頭の無音または遅いBass開始がないか |
| 50 ms時間軸 | 0〜2秒の軌跡 | RMS、Low、Low-mid、Onset差分 |

## 一変数検証の成立条件

010の仮説変数は「0〜2秒をBass主体・中央定位の構造にすること」であり、001-E01の目的と整合する。一方で、反復可能な一変数比較として因果を判断するには、各実行で数値を固定し、基準候補との違いを一つに限定する必要がある。[3]

| 状況 | 判定 | 010の対応 |
|---|---|---|
| Prompt・Negative・目的が記録済み | 受入可能 | 現在の正本通信ファイルに記録済み |
| Weirdness、Style Influence、Durationが範囲指定 | 未固定 | 生成前に実行値を1つずつ記録する |
| Safe Zone、Strongの値が未記録 | 未充足 | 生成前に有効／無効または実行値を追記する |
| 比較元となる直前候補の固定条件が未添付 | 因果比較は保留 | 010を受入候補として測定し、次の候補では010から1項目だけ変更する |
| 候補音源・公開URL・ハッシュが未受領 | 解析不可 | 音源受領後に候補manifestを作成する |

このため、010を**音響測定に進める候補条件として受領**する。一方、「010だけで一変数の因果が証明された」とは判定しない。次候補を010との比較群とし、Bass導入構造以外の設定を完全に固定すれば、001-E01の一変数検証として追跡できる。

## 実測後の返却予定

候補を受領したら、001正本と同一条件でRMS、Peak、Crest、帯域比、スペクトル重心、Stereo、持続信号開始、50 ms Onset軌跡を測定する。全体ミックス測定だけではPiano、Drums、Melody、クリック／機械的ノイズの不存在を断定しない。これらは必要に応じて補助的stem確認と人の聴取で追認する。[3]

正式返却は`docs/momoka/reports/latest_report.md`に状態、測定結果、Fact/Hypothesis/Evidence/Result、成功／失敗、次の一変数を記載し、本詳細レポートへリンクする。
