# 001・002再現解析システム｜初回回帰テスト

**実行日:** 2026-08-27（GMT+9）
**システム:** `tools/cafe_reproduction_analyzer.py` v1.0
**テスト:** 001／002正本を同一ファイルと比較する自己比較回帰テスト

## 結論

001・002の両方で、正本と同一の自己比較候補が再現スコア100.00を返し、JSON、CSV、比較図を生成した。可視化上もMasterとSELF-CHECKの曲線・帯域塗り分けは一致しており、同一入力に対する測定と描画は一貫している。

> この合格は、解析パイプラインの再現性を検証するものであり、候補曲の音楽的再現度、楽器の不存在、ノイズの有無を保証するものではない。

## 001の基準プロファイル（0〜2秒）

| 指標 | 測定値 | 読み取り |
|---|---:|---|
| RMS | -22.64 dBFS | 導入は全体として抑制されている。 |
| Low比率（20〜180 Hz） | 96.68% | 低域が明確に優勢である。 |
| Low-mid比率（180〜2,000 Hz） | 3.04% | 中低域は小さい。 |
| スペクトル重心 | 113.7 Hz | 低い重心である。 |
| Side/Mid比 | -32.40 dB | 左右差が非常に小さい。 |
| 持続信号開始 | 0.40秒 | 50 ms窓・-55 dBFS・2窓連続という本システム定義による。 |
| Low優勢窓割合 | 65.00% | 50 ms窓中、Low比率80%以上の割合。 |

可視化では、0.00〜0.35秒は低いRMSで推移し、0.40〜0.50秒付近に明瞭な立上がりがある。0.00〜0.95秒は概ねLowが支配的だが、1.00秒以降には帯域構成の変化が現れる。この時間構造を、候補の導入部評価の基準とする。

## 音源分離補助の実行検証

001正本の先頭15秒を検証クリップとして切り出し、`tools/cafe_stem_assist.py`からHybrid DemucsのBass分離を実行した。`bass.wav`と`no_bass.wav`、ハッシュを含むmanifestが生成され、スクリプトの実行経路は合格した。

| 項目 | 結果 |
|---|---|
| 入力 | `001_first15s.wav`（001正本から作成した検証用クリップ） |
| 分離モデル | `htdemucs`、CPU、Bass二分離 |
| 出力 | `bass.wav`、`no_bass.wav`、stem manifest |
| 判定 | 実行・追跡は合格。楽器の不存在やノイズの有無は、分離結果だけで断定しない。 |

検証用の分離WAVはサイズが大きいためGit追跡しない。実行manifestのみを必要に応じて保持し、候補曲やFender Studioのステムが届いた際に個別検証へ使用する。
