# 共通実験台帳

`generation_registry.jsonl` は、1行を1候補曲として扱う正本台帳です。生成曲の音源そのものを重複保存するものではなく、参照モデル、Prompt版、SUNO設定、音源の所在、分析、評価、最終判断、次の一変数を接続します。

| ルール | 内容 |
|---|---|
| 正本性 | 新しい候補曲は、分析・評価報告だけでなく台帳へ1行追加する |
| 音源証跡 | `asset_available_in_repo` と `asset_uri` を必ず記録し、未提供音源をあたかも再測定可能と扱わない |
| Promptと設定 | 不明なら`not_recorded`と明記する。推測で補完しない |
| 再現率 | `score_status`に計算式・既存報告値・未採点を区別して記録する |
| 次回検証 | `next_single_variable`へ、変更する変数を1つだけ記録する |

> **台帳とPattern DBの関係:** 台帳は「何を生成・評価したか」、Pattern DBは「どのEvidenceを次回設計に使えるか」を管理します。
