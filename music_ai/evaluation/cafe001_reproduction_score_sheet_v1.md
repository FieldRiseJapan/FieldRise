# Cafe001 再現率評価シート Ver.1

## 📋 概要
本評価シートは、FieldRise Music AIの最優先目標である「成功モデル001（TikTok 5.9万本利用の『cafe』）を90%以上の精度で再現する」ために、生成された楽曲が成功モデル001とどの程度一致しているかを数値化し、客観的に評価するためのテンプレートである。彩花CTOの指示に基づき、Cafe 003以降のすべての生成楽曲を同一基準で比較・改善することを目的とする。

---

## 🎯 目的
感覚的な評価ではなく、データに基づいた改善サイクルを確立し、FieldRise Music AIが安定して「動画に選ばれるBGM」を生成できる能力を向上させる。

| 評価項目 | 評価基準（Cafe001 DNAとの比較） | 一致率 (%) | 評価コメント |

| **Bass** | ウォーキングベースの安定性、音色、存在感 | | |

| **Brush Drum** | アタックの柔らかさ、リズムの軽快さ、音色 | | |
| **Rest（余白）** | ナレーションやASMRを邪魔しない「空間」の確保度 | | |
| **Voiceover Friendly** | 声や環境音との共存性、中域のクリアさ | | |
