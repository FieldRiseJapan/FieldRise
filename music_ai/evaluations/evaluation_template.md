# FieldRise Music AI 評価システム Ver.1.0

## 評価基準 (100点方式)

各項目を以下の配点で採点し、客観的な品質管理を行う。

| 評価項目 | 配点 | 採点基準 |
| :--- | :---: | :--- |
| **Intro (最初2秒)** | 20点 | 0〜2秒で低いBassが効いているか。唐突な開始ではないか。 |
| **Piano表現** | 20点 | ピアノの音色が柔らかく、感情的か。カフェの雰囲気に合っているか。 |
| **Cafe世界観** | 20点 | 全体を通して落ち着いた「引き算の美学」が守られているか。 |
| **BGM適性** | 15点 | 主張しすぎず、作業や会話を邪魔しない構成になっているか。 |
| **Loop性** | 15点 | 終わりの部分から始まりへ自然に繋がるか。 |
| **SNS利用可能性** | 10点 | TikTokやInstagramのリール動画の背景として使いやすいか。 |
| **合計** | **100点** | **80点以上を採用候補、90点以上を成功モデルとする。** |

---

## 評価フロー
1. 桃花（COO）が生成された楽曲を聴取。
2. 本テンプレートに基づき各項目を採点。
3. 採点結果を `generation_logs/` に記録。
4. 低スコアの場合は、彩花（CTO）へフィードバックを行いプロンプトを改善。
