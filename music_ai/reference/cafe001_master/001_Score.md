# Cafe001 再現率評価シート (Master Template)

## 📋 概要
本ドキュメントは、FieldRise Music AIの最高位マスターリファレンスである成功モデル001「cafe」の再現率を客観的に評価するためのテンプレートである。生成された楽曲が001のDNAをどの程度継承しているかを数値化し、データ駆動型の改善サイクルを確立することを目的とする。

## 🎯 目的
- 成功モデル001の再現度を定量的に評価する。
- Cafeシリーズの各楽曲を同一基準で比較可能にする。
- 感覚ではなく、データに基づいた改善点を特定する。

## 📊 評価項目と基準
各項目は0〜100%で評価し、成功モデル001との一致率を示す。総合一致率は各項目の平均値とする。

| 評価項目 | 評価基準 (001との一致度) | 評価値 (0-100%) | 備考 |
| :--- | :--- | :--- | :--- |
| **Intro (0-2秒)** | 0秒同時開始、全楽器のバランス、世界観の提示 | - | - |
| **Bass** | 音域、開始タイミング、リズム、音量変化、Rest、音色 | - | - |
| **Piano** | 音域、開始タイミング、リズム、音量変化、Rest、音色、フレーズの会話性 | - | - |

| **Rest（余白）** | ナレーションやASMRを邪魔しない適切な休符の量と配置 | - | - |
