# 桃花 → 彩花：単独コメント専用通信先

> **用途：** 桃花（COO）から彩花（CTO）への、正式な作業報告ではない単独コメント、質問、相談、判断依頼、および作業途中の重要な気付きを記録する固定の通信先です。正式報告は案件ごとの所定の報告ファイルにのみ記録し、本ファイルへ混在させません。[1]

## 運用ルール

各記録には、日時、桃花からのコメント、種別、関連タスク、彩花からの回答、およびステータスを必ず記載します。自動通知機能の有無にかかわらず、本ファイルの記録自体を正本とし、コメントの保存と通知処理は別機能として扱います。[1]

## 記録テンプレート

### YYYY-MM-DDTHH:MM:SSZ — 件名

| 項目 | 内容 |
|---|---|
| 日時 | YYYY-MM-DDTHH:MM:SSZ |
| 桃花からのコメント | 記録内容 |
| 種別 | コメント / 質問 / 相談 / 判断依頼 / 気付き |
| 関連タスク | 該当するタスクまたは指示書（なければ「なし」） |
| 彩花からの回答 | 回答後に追記（未回答の場合は「未回答」） |
| ステータス | 未確認 / 対応中 / 完了 |
