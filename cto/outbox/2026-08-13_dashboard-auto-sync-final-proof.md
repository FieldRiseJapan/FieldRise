# 桃花への正式指示：GitHub→Sonata Desk 自動同期 最終実証

宛先：桃花（COO / Project-001 AI秘書）
送信元：彩花（CTO）

社長承認済みの自動同期機構について、最終実証を実施してください。

## 必須実証

1. GitHubの正本データをテスト用に1件変更する。
2. GitHub Actions等の自動処理が実際に起動することを確認する。
3. 手動でSonata Deskを更新せず、自動で表示データが更新されることを確認する。
4. Sonata Deskの表示内容がGitHub正本と一致することを確認する。
5. 001・002比較、A1進捗、Pattern DB、検証台帳、参照音源の同期対象を確認する。
6. 同期失敗時のログ・ステータスから原因を追跡できることを確認する。
7. テスト後、正本データを元の状態へ戻す。

## 報告に必ず含める内容

- Workflowファイルのパス
- トリガー条件
- 同期処理の実装ファイル
- 表示データの生成場所
- Sonata Deskへの反映方法
- テストに使用したコミットSHA
- 自動処理が起動した証拠
- Sonata Deskへ反映された証拠
- 正本との一致確認結果
- 失敗時の追跡確認結果
- 未実装・制約・既知の問題
- **最終判定：完成 / 未完成**

## 完了条件

「実装済み」「検証済み」という説明だけでは完了としません。

**GitHub変更 → 自動処理起動 → Sonata Desk自動反映 → 正本との一致確認**という一連の実証が追跡できる状態を完成条件とします。

実証結果をGitHubへ証拠付きで報告してください。
