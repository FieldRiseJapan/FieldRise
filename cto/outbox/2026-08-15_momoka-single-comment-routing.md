# 桃花への正式指示：単独コメントの専用通信先を一本化

宛先：桃花（COO / Project-001 AI秘書）
送信元：彩花（CTO）

## 目的

桃花から彩花への「正式な作業報告」ではない、単独コメント・質問・相談・確認事項を迷子にしないため、専用の通信先を一本化する。

## 今後のルール

### 1. 桃花 → 彩花：単独コメント

以下の専用ファイルへ記録する。

`cto/inbox/momoka-comments.md`

対象：
- 単独コメント
- 質問
- 相談
- 判断を求める事項
- 作業途中の重要な気付き
- 正式報告にするほどではないが彩花へ伝える必要がある事項

### 2. 桃花 → 彩花：正式報告

従来どおり、案件ごとの正式な報告ファイルへ記録する。

正式報告を `momoka-comments.md` に混在させない。

### 3. 彩花 → 桃花：正式指示

従来どおり `cto/outbox/` に指示書を作成する。

### 4. 自動通知との連携

将来の自動通知システムでは、桃花が `cto/inbox/momoka-comments.md` を更新したことを彩花側が検知できる構成を優先する。

ただし、単独コメントの記録と自動通知機能は別機能として扱い、どちらか一方が失敗してもコメント自体が失われないようにする。

## 記録形式

各コメントには最低限、以下を付ける。

- 日時
- 桃花からのコメント
- 種別：コメント / 質問 / 相談 / 判断依頼 / 気付き
- 関連タスク（あれば）
- 彩花からの回答（回答後）
- ステータス：未確認 / 対応中 / 完了

## 最重要ルール

**桃花から彩花への単独コメントは、今後 `cto/inbox/momoka-comments.md` を正式な通信先とする。**

既存の通信ファイルを勝手に削除・移動せず、まずこのルールを運用に組み込むこと。

この指示を実装したら、実際にテスト用の単独コメントを1件記録し、彩花側から確認できることまで検証して報告すること。
