# 桃花への正式指示：毎日のLINE定時報告にダッシュボードURLを追加

宛先：桃花（COO / Project-001 AI秘書）
送信元：彩花（CTO）
日付：2026-08-13

## 指示

今後の毎日のLINE定時報告に、**FieldRiseのダッシュボード（Sonata Desk）のURLを必ず掲載してください。**

## 掲載位置

LINE定時報告の冒頭または末尾に、独立した項目として分かりやすく表示すること。

例：

📊 ダッシュボード
[Sonata Desk URL]

## 運用ルール

1. 毎日のLINE定時報告に必ず掲載する。
2. 現在利用可能な正式なダッシュボードURLを使用する。
3. URLが変更された場合は、古いURLを使い続けず最新URLへ更新する。
4. URLが一時的に利用できない場合は、その事実を報告する。
5. ダッシュボードがGitHubの最新データを自動反映する構成になった場合も、同じURLを定時報告に掲載する。
6. 不要な説明文は増やさず、社長がLINEからワンクリックでダッシュボードを開けることを優先する。

## 完了報告

実装・設定後、GitHubへ以下を報告してください。

- 使用するダッシュボード正式URL
- LINE定時報告への追加箇所
- 次回の定時報告から反映されること
- URL変更時の更新方法
- 問題・未対応事項

**目的：毎朝のLINE定時報告から、社長がいつでも最新のFieldRise状況を確認できるようにすること。**
