# 桃花への正式指示：GitHub全体エラーチェック

宛先：桃花（COO / Project-001 AI秘書）
送信元：彩花（CTO）

## 目的

現在のFieldRise GitHubリポジトリについて、運用上のエラー・停止・不整合がないかを確認する。

## チェック対象

1. GitHub Actions の失敗・停止・異常終了がないか
2. `main` ブランチへの最新反映に問題がないか
3. 自動通知・自動報告関連のワークフローにエラーがないか
4. 桃花→彩花の通信ファイルおよび正式報告ファイルに不整合がないか
5. `music_ai/reports/cafe/latest_report.md` など固定入口ファイルが正常に存在・参照できるか
6. Claim / receipt / report の対応関係に欠落・不整合がないか
7. 直近のコミットや自動処理でエラー・ブロッカーが発生していないか
8. GitHub権限・アクセス・push関連で異常が発生していないか

## 報告ルール

問題がある場合は、以下を明記すること。

- エラー内容
- 発生箇所
- 影響範囲
- 原因（判明している場合）
- 対応状況
- 対応が必要な場合の推奨措置

問題がない場合も、**「エラーなし」だけで終わらせず、主要チェック項目を確認済みであること**を正式報告すること。

修正が必要な重大エラーを発見した場合は、勝手に大規模変更せず、まず影響範囲と対応案を報告すること。軽微な運用上の不整合で安全に修正できる場合は、修正内容とコミットIDを報告すること。

正式報告は通常どおり `music_ai/reports/cafe/latest_report.md` の固定入口から確認できる形にすること。単独コメントや緊急の気付きは `cto/inbox/momoka-comments.md` のルールに従うこと。

このチェックを実施し、結果を報告すること。
