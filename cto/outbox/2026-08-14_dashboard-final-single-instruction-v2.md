# 桃花への正式指示：ダッシュボード最終確認・運用状態確認（再発行）

宛先：桃花（COO / Project-001 AI秘書）
送信元：彩花（CTO）

社長が混乱しないよう、ダッシュボード関連の確認指示をこの1枚に再整理します。

## 目的
現在のSonata Deskが、社長が実際に使える状態で正常運用されているかを確認する。

## 必須確認
1. 現在の正式なSonata Desk公開URL。
2. 公開URLへ実際にアクセスできること。
3. GitHub mainの最新コードが公開URLへ反映されていること。
4. Decision Brief / Evidence Integrity / Open Review Queueが表示されること。
5. 001・002比較、A1進捗、Pattern DB、検証台帳、参照音源が正常に利用できること。
6. GitHub正本データがダッシュボードに反映されていること。
7. GitHub→ダッシュボード自動同期が現在も正常に動作していること。
8. sourceDigest等を利用して正本との一致を確認すること。
9. LINE定時報告に正式URLが掲載される設定が有効であること。
10. 直近の同期・復旧・バックアップ関連変更に問題がないこと。

## 完了条件
以下をすべて確認できた場合のみ「運用継続可能」と判定する。

- 公開URLが正常
- 最新UIが公開済み
- GitHub正本と表示データが一致
- 自動同期が正常
- LINE URL掲載が正常
- 社長が追加作業なしで利用可能

1つでも確認できない場合は「要修正」とし、原因と必要な対応を明記する。

## 報告
GitHubへ1つの最終報告として以下を記録すること。

- 正式URL
- 確認日時
- 使用コミットSHA
- UI確認結果
- データ同期結果
- sourceDigest等の照合結果
- 自動同期テスト結果
- LINE掲載確認結果
- 直近変更の影響
- 未解決事項
- **最終判定：運用継続可能 / 要修正**

## 重要
新しいダッシュボードを作り直さないこと。既存のSonata Deskを対象とする。
過去のダッシュボード指示は参考資料とし、この指示書を今回の確認基準とする。
