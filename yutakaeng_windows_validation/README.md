# yutakaeng Windows検証アプリ

## この検証版で確認する流れ

1. `yutakaeng.exe` を起動します。
2. 画面中央へ、複数ページの配線図PDFをドラッグ＆ドロップします。
3. 画面に英語コード風ログ、ページ進捗、経過時間、推定残り時間が表示されます。
4. 解析が終わると、Windowsのデスクトップに確認用Excelが自動作成されます。
5. Excelは電線コード・サイズごとにシートを分けます。たとえば`Y5`ならシート名も`Y5`です。
6. 各シートで候補行を元PDFと照合し、`確認状態`を更新します。

> この版は**検証用**です。OCR候補を自動確定しません。未確認・警告・対象外をExcelに残し、利用者が全行確認して警告が0件になるまで、ホットマーカー用の最終データとしては使用しません。

## 実装済みの除外・照合ルール

| 条件 | 判定 |
|---|---|
| DT1・DT2などのDT系端子台 | 対象外 |
| `D-Y0.5`、`D-B0.5`などD-始まり線コード | 対象外 |
| 端子台接続先の`I/L`、`I/YF...`、`I-Y...` | 盤内行きとして対象外 |
| ZTブロックの`LEFT-Y5`、`RIGHT-Y5` | 隣接盤への盤間配線として対象に残す |

## Windowsでの起動

GitHub Actionsで作成された`yutakaeng-windows-validation`の成果物を展開し、フォルダ内の`yutakaeng.exe`をダブルクリックします。初回起動時にWindowsの保護画面が出る場合は、検証版であることを確認したうえで「詳細情報」から実行します。

## 出力されるExcel

オーダー番号を読めた場合は`オーダー番号.xlsx`、読取が未確定の場合は`要確認_元PDF名_日時.xlsx`としてデスクトップへ保存します。先頭の`概要`シートには入力PDF、候補行数、対象外行数、警告行数、出力場所を記録します。

電線コードごとのシートには、PDFページ、枠ID、見出し、主文字候補、左右接続先候補、読取状態、確認状態、警告・除外理由を収録します。
