yutakaeng Windows検証版（持ち運び用）

1. このフォルダ全体を、USBメモリーまたは会社PCの任意の場所へコピーします。
2. フォルダ内の yutakaeng.exe をダブルクリックします。
3. 配線図PDFを画面へドラッグ＆ドロップします。
4. 解析中はコード風ログ、進捗、推定残り時間が表示されます。
5. 完了すると、確認用ExcelがWindowsデスクトップに作成されます。

重要:
- この版は主文字専用のローカルOCRモデルをフォルダ内に同梱しています。会社PCがネット未接続でも、PDFや図面データを外部へ送信せずに動作します。
- 主文字は行番号・丸囲み記号・右端端子番号を除いた中央セルだけを広狭2通りで読み、結果が一致するか末尾の欠けだけを補完できる場合だけ候補としてExcelへ出します。
- 左右接続先は中央枠の外側だけを別々に読みます。主文字・端子番号・隣の枠を接続先候補へ混ぜない方式です。
- 無意味な文字列、読取不能、候補不一致、端子枠の混入、先頭文字欠落は空欄にして警告を出します。推測で確定しません。
- 見出しや電線サイズを特定できない枠・行は、電線サイズ別シートに混ぜず「警告一覧」シートへ隔離します。
- Excelの各線コードシートは「マーク主文字」「マーク個数」「読取状態」「確認状態」「L側接続先」「R側接続先」を左端に並べます。図面照合用の見出し・ページ・枠ID・警告理由は右側に残します。
- マーク個数は、主文字を安全に読めた別電線1本につき2個です。主文字未読取の警告行は0個として出力します。
- Excelは警告行だけを確認・修正してください。警告がない行は「確認不要」と表示され、全行を1本ずつ確認する運用ではありません。読み取れない項目や行き先不明は「警告あり」とし、右端の「警告・除外理由」に主文字・L側・R側などの未読取項目を明記します。
- DT系端子台、D-始まり線コード、端子台接続先の単独Iは対象外です。
- ZTブロックのLEFT/RIGHTは隣接盤との盤間配線であり、対象に残ります。
- 「マーク主文字」は、読取できた場合に「盤番号-見出しまたは端子台-主文字」の順で出力します。たとえば盤番号1AのYF枠なら`1A-YF-FL1A11`、盤番号3AのT1(2)なら`3A-T1-BTBT2BP`となります。盤番号や見出しが未読取の場合は推測で補わず、警告として残します。
- 電線サイズ別シートは、図面から実際に抽出できたサイズだけを作成します。サイズを判別できない行や見出しを分類できない行はサイズシートへ混ぜず、「警告一覧」へ集約します。

トラブル時:
- フォルダ内のファイルを削除せず、フォルダ全体をコピーし直してください。特に _internal フォルダにはオフラインOCRモデルと実行用ライブラリが含まれます。
- Windowsの保護画面が表示された場合は、検証版であることを確認してから「詳細情報」→「実行」を選んでください。


今回の追加機能:
- PDFをドロップして解析中は、入力画面を一時的に隠し、コード風の処理ログを画面いっぱいに表示します。
- ページ総数を先に取得し、解析開始直後から推定残り時間を表示します。ページ処理時間を実測して推定値を更新し、カウントダウンは250ミリ秒ごとに減少します。推定値は処理量の目安であり、PC性能やPDF内容によって変動します。
- ローカル再読取後も警告が残った場合だけ、「Copilotへ警告セルを確認依頼」ボタンを表示します。正常行には表示しません。
- ボタンでは警告セル画像を1枚だけ利用者が選択します。選択した画像をプレビュー確認してから、画像を開き、Copilotのページを開きます。画像をCopilotへ添付する操作は利用者が手動で行います。PDF全体や複数ページを自動送信する機能ではありません。
- Copilotの回答は補助候補です。自動でExcelへ確定反映せず、原図または画面表示と照合して利用者が確認してください。会社のMicrosoft 365管理者が許可したCopilot利用条件に従ってください。
- 外部送信を一切したくない場合は、Copilotボタンを使用せず、従来どおりローカルOCRとExcel確認だけで運用できます。


【Excelの見出し配置について】
電線サイズごとのシートでは、見出し（例：YF、ZF、T1、IF）をグループの先頭に単独行で表示し、その直下に主文字を並べます。主文字の各行へ見出しを重複付加する方式ではありません。主文字は写真の例に合わせ、YF-FL1A11、ZF-B-BTB2C6、T1-TB2F1A1のように、見出しまたは端子台識別子を先頭へ付けます。盤番号はシート上部の「盤番号」欄で確認できます。

【確認方法】
正常に読み取れた行は「確認不要」と表示されます。主文字、L側接続先、R側接続先、行き先、電線サイズなどに不確かな部分がある行だけ「警告あり」「警告確認」と表示されます。警告行の主文字はExcel上で直接修正してください。


【線サイズがない行について】
図面に電線サイズが書かれていない行、またはOCRで電線サイズを安全に読めない行は、削除せず「線サイズ未記載」シートへ出力します。このシートの行は「警告あり」「警告確認」と表示され、右端の「警告・除外理由」に「線サイズ未記載または未読取」と明記されます。Excel上で線サイズを入力・修正した後、必要なサイズのシートへ移動できます。


【電線サイズの分類】
電線サイズが安全に読み取れた行は、サイズ名のシート（例：Y2、Y5）へ出力します。図面上にサイズの記載がない行は「線サイズ未記載」シートへ、記載らしき文字はあるものの安全なサイズ形式として判別できない行は「線サイズ判別不明」シートへ出力します。両シートとも行を削除せず、警告理由を明記します。


【盤内線ボタン】
PDFドロップ画面の「盤内線」ボタンを押すとPDF選択画面が開き、端子台側のI表記を含む盤内線だけを抽出します。通常のPDFドロップ解析では従来どおりI表記を盤内行きとして除外します。盤内線モードでも、推測補正は行わず、主文字や行き先を読めない行は警告としてExcelへ残します。出力形式は通常解析と同じで、電線サイズ別シート、線サイズ未記載、線サイズ判別不明、見出し単独行を使用します。


【Xブロックボタン】
PDFドロップ画面の「Xブロック」ボタンを押すと、X1、X2などのXブロック見出しを持つ枠だけを抽出します。YF、T1、IFなど他のブロックは対象にしません。抽出後のExcelは通常解析と同じ形式で、電線サイズ別シート、線サイズ未記載、線サイズ判別不明、見出し単独行を使用します。通常の安全除外ルールは維持され、不確かな文字は警告として残ります。

総点検で、解析終了後に「盤内線」「Xブロック」ボタンが再表示されない問題を修正しました。解析終了後は、PDFドロップ、PDF選択、盤内線、Xブロックのすべての操作を再び利用できます。
